
# Planning Poker Estimation Tool

A simple, responsive Planning Poker estimation tool built with React, TypeScript, and Material UI.

## Features
- Enter your name (editable at any time)
- Select an estimation card (1, 2, 3, 5, 8, 13, ?)
- Reveal/hide your selected card
- Reset to clear selection and name
- Dark mode toggle
- Responsive and accessible UI
- Subtle animations for card selection

## Getting Started

### Prerequisites
- Node.js (v18 or newer recommended)

### Install dependencies

```
cd planning-poker
npm install
```

### Run the app

```
npm run dev
```

The app will be available at `http://localhost:5173` (or the port shown in your terminal).

## Project Structure
- `src/App.tsx` — Main app UI and logic
- `src/main.tsx` — App entry point and theme provider
- `public/` — Static assets
